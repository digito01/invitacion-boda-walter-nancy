# Invitación de Boda — Walter & Thatiana

Invitación digital interactiva con:
- Sobre animado con sello de lacre y monograma
- Enlaces personalizados por invitado (`?invitado=Nombre&pases=2` o `?id=...`)
- Cuenta regresiva editable
- Secciones por bloques (padres, ceremonia, recepción, itinerario, código de vestimenta, mesa de regalos, galería)
- RSVP con confirmación de asistencia
- Panel de administración (`?admin=1`) para generar enlaces, revisar respuestas, subir fotos y exportar a Excel

## Ver la página en línea

Una vez activado GitHub Pages en este repositorio (Settings → Pages → Branch: main), la invitación estará disponible en:

```
https://digito01.github.io/invitacion-boda-walter-thatiana/
```

Panel de administración:

```
https://digito01.github.io/invitacion-boda-walter-thatiana/admin.html
```

(Estos enlaces solo funcionan después de renombrar el repositorio a `invitacion-boda-walter-thatiana` desde GitHub → Settings → Repository name.)

## Editar contenido

Todo el contenido (nombres, fecha, direcciones, secciones) se edita desde el panel de administración, sin tocar código.
